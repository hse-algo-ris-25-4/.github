# Добро пожаловать на курс «Алгоритмы и структуры данных», 2026/2027 👋

Курс реализуется в офлайн-формате: лекции и семинары проводятся очно.

## Как попасть в организацию

1. Зарегистрироваться на [GitHub](https://github.com).
2. Отправить преподавателю логин учётной записи — вас добавят в организацию.
3. **Принять приглашение** в почте или на GitHub: репозитории публичные, клонировать можно сразу, но без членства в организации нельзя выполнять задания.
4. Настроить рабочее место и клонировать репозитории по инструкции [Установка необходимого ПО](https://github.com/hse-algo-ris-25-4/docs/blob/main/installing-software.md).

## Репозитории

- [code-tasks](https://github.com/hse-algo-ris-25-4/code-tasks) — программные задания, **Python 3.14**, [VS Code](https://code.visualstudio.com/). Задание выдаётся отдельной веткой `main-task-*`, pull request открывается **в ветку задания** и после ревью **не вливается**.
- [manual-tasks](https://github.com/hse-algo-ris-25-4/manual-tasks) — ручные задания, оформление в Markdown. Окружение Python не нужно. Pull request открывается в `main` и после ревью **вливается**.
- [docs](https://github.com/hse-algo-ris-25-4/docs) — инструкции: установка ПО, сдача кода, схема ветвления.

Правила веток и pull request в двух репозиториях с заданиями **разные**; подробности — в README каждого из них и в [схеме ветвления](https://github.com/hse-algo-ris-25-4/docs/blob/main/branching-model.md).
