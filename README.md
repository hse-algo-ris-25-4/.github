# .github

Служебный репозиторий организации: в нём лежат файлы, которые GitHub показывает
на странице организации и в новых issues.

- `profile/README.md` — текст на главной странице: https://github.com/hse-algo-ris-25-4
- `ISSUE_TEMPLATE/` — шаблон обращения об ошибке в задании или инструкции (общий для всех
  репозиториев организации)

Материалы курса — в репозиториях [code-tasks](https://github.com/hse-algo-ris-25-4/code-tasks),
[manual-tasks](https://github.com/hse-algo-ris-25-4/manual-tasks) и [docs](https://github.com/hse-algo-ris-25-4/docs).
